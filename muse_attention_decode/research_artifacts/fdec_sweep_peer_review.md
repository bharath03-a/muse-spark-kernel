Grouped heads, full causal L1 context including the written new row, sm_scale0.125, per-head output RMS and gate sigmoid match `reference.py` for this geometry. Independent new K/V cache checks occur before timing. Each candidate starts from a fresh clone of the same original caches; replay rewrites the same deterministic new row. Baseline is independently validated, so it does not silently establish a poisoned reference.
- **ABBA timing checked:** each pair runs base/candidate/candidate/base with a cold-L2 flush before every measured graph replay, and geometric pairing cancels first-order order bias. Ten ABBA repetitions are retained per B/seed/variant; two seeds provide separate repeats. Closures returned by `build_call` freeze separate frames, buffers and module handles; captured graph state remains alive. CUDA failures rethrow rather than attempting recovery in a sticky context.
- **Log retention concern:** 16 candidate results with 20 dictionary samples each, plus baseline records, can exceed the judge's 16000-character tail. Emit a compact final summary containing every B/seed/variant, paired median, base/candidate median, numerical bounds and CUDA SHA. Prefer compact raw arrays over repeated dictionary keys so all raw samples also fit in the retained tail. Otherwise an early result can disappear even after a successful sweep.

A pre-build deadline with explicit remaining-time reserve is needed to leave time for official tests; a single in-process compile cannot be forcibly bounded by this check. Current deadline exhaustion raises and intentionally fails the diagnostic job.
- **Distribution limit:** all four datasets use independent Gaussian K/V/Q, not the scored coherent-key/coherent-tail distribution or agentic length spread. This is a useful memory/prefetch microbenchmark, but passing its reference checks does not establish correctness/performance on coherent scored inputs. A compact coherent case or the official tests remains necessary before promotion.
